# Визуальные конспекты теории

Все 47 теоретических разделов пособия и 10 правил демонабора получили визуальный конспект. Это авторское краткое изложение по теме: основной принцип, схема, конкретные правила, два разобранных примера, три шага решения, типичная ошибка. Для ряда тем добавлены сравнительные шпаргалки. Полный исходный материал остаётся отдельным раскрываемым разделом; ссылки на страницы PDF сохранены.

Содержание конспектов: `src/content/theory/`. Компонент: `src/app/VisualTheory.tsx`. Для собственной теории с неизвестным ID или другим источником используется прежний рендер её блоков — чужой материал не заменяется конспектом другой темы.

Схемы различают сопоставление категорий, последовательность действий и состав основы. Примеры размечены как текстовые части, HTML из содержимого не исполняется. Подлежащее подчёркнуто одной линией, сказуемое двумя; рядом текстовая легенда. Роль определяется авторской разметкой, не догадкой по слову.

Конспект загружается отдельным модулем, включённым вместе со стилями в офлайн-кеш. Пакет, ключи, версии заданий, IndexedDB и начисления опыта этим изменением не меняются. Уже сохранённый банк получает новый вид после обновления приложения.

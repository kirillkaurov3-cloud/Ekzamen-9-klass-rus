# Таблицы ключа №7

Редакция: `f6ed218ac5b38133e1042d34cabd6cc13ce63b837dd6f4696c5dac85267bf127`. Физические страницы 480–532. 90 исходных вопросов, по девять позиций: 810 строк. Столбцы: позиция, часть речи, морфема, правило/проверочное слово, восстановленное слово.

Локальный извлекатель `scripts/semantic_tables.py`, PyMuPDF 1.26.6. Номер таблицы берётся из отдельного заголовка вопроса, строка ключа — из его «ОТВЕТ», продолжение на следующей странице относится к предыдущему заголовку до появления нового. Ячейки читаются по линиям таблицы; переносы внутри ячейки становятся пробелами. Одна известная разорванная ячейка 491/q19/3 (`В Д.п. сущ. пишется окончание` + `ЯМ`) визуально сверена и объединена; без точного совпадения исходных частей правило не применяется.

Валидация запрещает другую редакцию/версию разметки, неизвестные или пропущенные вопросы, повтор позиции, неполную строку, пустую ячейку, приватный шрифтовой символ. Импорт дополнительно сопоставляет исходный ID, ключ, страницы и позиции `(1)`–`(9)` условия. Несогласованный файл останавливает импорт. Изменение семантического файла меняет packVersion.

В опубликованном банке изменены только объяснения и версии 90 записей `oge7-topic1-qN-table`: v1 → v2, тип self и reviewRequired сохранены. Обычные вопросы и их оценки не меняются. Проверены все девять слов q57 (стр.512); те же позиции используются в пяти вручную подготовленных буквенных интерактивах.

Это восстановление структуры источника, а не независимая проверка лингвистической точности всех 810 формулировок. В ключах встречаются спорные формулировки. Таблицы остаются самопроверкой без объективной оценки, XP за «верный ответ» и допуска в диагностику/мини-вариант. Оригинал можно открыть локально в PDF-просмотрщике. Ни PDF, ни промежуточный файл разметки не публикуются.

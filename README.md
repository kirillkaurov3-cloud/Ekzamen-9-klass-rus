# Запятая

Тренажёр ОГЭ по русскому: диагностика по десяти номерам, темы и номера, мини-варианты с таймером, повторение ошибок, теория и статистика. Прогресс хранится на устройстве в IndexedDB. Публичная сборка содержит собственные демозадания и отдельно скачиваемый банк пособия, опубликованный по явному выбору владельца для общего доступа.

Сайт: https://kirillkaurov3-cloud.github.io/Ekzamen-9-klass-rus/

Выполненные этапы, фактические проверки и оставшиеся задачи: [PROGRESS.md](PROGRESS.md).

## Запуск

Node.js **24.22.1** из `.nvmrc`, npm и Python 3.10+ для тестов импортера.

```bash
npm ci
npm run dev
```

Dev: `http://localhost:5173`. Для production и офлайна:

```bash
npm run build
npm run preview
```

Preview: `http://localhost:4173`. Для установки откройте HTTPS-сайт; на iPhone — Safari → «Поделиться» → «На экран Домой». Сначала загрузите сайт с сетью. Обновление предлагается кнопкой после завершения активной серии. Очистка данных сайта удаляет локальный прогресс; облачная синхронизация пока не реализована.

## Банк пособия

Откройте на сайте [«Банк заданий»](https://kirillkaurov3-cloud.github.io/Ekzamen-9-klass-rus/#/library) и нажмите «Загрузить и открыть пособие». Объём — около 3.1 МБ. После загрузки каталог, теория и ответы работают офлайн. Сохранённый банк можно открыть повторно без сети, даже после переключения на демо. Прогресс обоих наборов сохраняется отдельно.

Файл доступен в `public/packs/praktikum-2027.json`. Банк содержит все 1627 записей, распознанных текущим импортом: 1411 с автоматической проверкой и 216 для самопроверки. Это не подтверждение полного переноса всей книги. Исходный PDF, постраничные выгрузки и рабочие отчёты остаются локальными.

Загрузка проверяет размер, SHA-256 и схему. Повреждённый файл не заменяет текущий набор. Банк не загружается автоматически в кэш оболочки; он сохраняется в IndexedDB после явного открытия.

## Диагностика и практика

На главной выберите «Узнать, с чего начать». В серию включаются только задания с отметкой ручной проверки (`verification: manual`), без ключей на сверке. Серия содержит по одному заданию на номера 2–9, 11 и 12, без таймера. Черновики сохраняются; оценки и ключи появляются после сдачи. Результат — первичная оценка, а не устойчивый уровень знаний. При недостаточном покрытии набора диагностика недоступна, каталог остаётся открыт.

«Следующий шаг» предлагает тему, правило с примерами и короткую практику. Рекомендация пересчитывается по последним актуальным ответам; исправленные ошибки и пропуски не считаются текущими ошибками. Прежний прогресс не сбрасывается.

## Интервальное повторение

На главной и в прогрессе есть «Повторение по плану» (`#/repeat`). Первый проверенный ответ назначает вопрос на завтра; самостоятельный успех в назначенной серии увеличивает интервал до 3, 7 и 14 календарных дней. Далее интервал остаётся 14 дней. Ошибка возвращает один день. Досрочное верное решение в свободной практике срок не сдвигает. В серии не больше пяти вопросов; остальные остаются в очереди.

Назначения восстанавливаются из сохранённых попыток, с дедупликацией по ID события. Для новых ответов сохраняется локальная дата; для прежних она определяется из времени ответа в часовом поясе устройства. Календарная арифметика учитывает границы месяцев, года и переходы летнего времени. Даты остаются календарными при смене часового пояса. Пропуски, самопроверка и старые версии заданий исключены. Резервное поле `hintUsed` возвращает короткий интервал; пользовательские подсказки в самостоятельном решении ещё не добавлены. Самооценка не создаёт объективного успеха.

Для диагностики пособия вручную сопоставлены стартовые задания и строки ключей по всем десяти номерам. [Протокол сверки](docs/content/diagnostic-verification.md). Обновление этих отметок не меняет версии заданий и сохраняет прогресс; любое изменение условия или ключа по-прежнему требует новой версии задания.

## Мастерская: буква и правило

Откройте пособие в библиотеке, затем «Мастерская правил» на главной или «Интерактив: буква и правило» в теме №7. Пять слов из задания 57 предлагают вставить букву и выбрать объяснение. Оценки двух шагов показываются отдельно; подсказка и открытие теории до проверки помечают попытку как решение с помощью. Есть исходный текст, страницы и переход к теории. Черновики, результаты и факт открытия подсказки сохраняются офлайн.

Учебные попытки отделены от обычных заданий и не увеличивают число решённых вопросов пособия. База IndexedDB обновляется с версии 1 до 2 добавлением таблицы, без удаления прежних данных. [Покрытие механик и происхождение разметки](docs/content/interactive-coverage.md). Остальные пять новых механик, XP и дневные уроки ещё не завершены.

## Локальный импорт PDF

Нужен Poppler (`pdftotext`). Исходник, пакет, текст, корректировки и отчёты остаются в игнорируемых `content-source/` и `content-private/`. Сам импорт ничего не публикует; в публичный каталог копируется только отдельно выбранный валидированный пакет.

```bash
mkdir -p content-source
# Поместите PDF в content-source либо укажите его путь в --input.
python3 scripts/import-pdf.py \
  --input content-source/Tematicheskiy_praktikum_2026-2027-2.pdf \
  --output-dir content-private/praktikum-2027
npm run content:validate -- content-private/praktikum-2027/pack.json
```

Загрузить готовый `pack.json` можно через настройки сайта. Файл обрабатывается и сохраняется на устройстве. При новой версии набора история сохраняется; изменение самого задания требует увеличения его `version`.

Импортер проверяет 545 страниц и границы разделов, сохраняет составные адреса и физические страницы. `REPORT.md`, `report.json` и `review.json` описывают реальное покрытие; наличие автоматического ключа не означает ручной сверки всего задания. Полнота переноса пока не подтверждена.

Теория связана с темами как фрагменты по страницам; блок `preformatted` сохраняет колонки и переносы. Семантическая разметка таблиц и просмотр оригинального PDF ещё не завершены.

Все спорные записи, включая задания №12 и таблицы разбора №7, доступны с отметкой «Ключ на сверке»: `reviewRequired: true`, тип `self`, без таймера и оценки. Очередь сверки включает эти записи, поэтому метрики «самопроверка» и «на сверке» пересекаются.

Ручные корректировки находятся в локальном `corrections.json`. Читаемые формы №9 (`answerForms`) должны сохранять все слова и альтернативы исходного ключа. Полная ручная запись (`task`) должна сохранять составной адрес и страницы. Оба вида привязываются к `sourceSha256` и `sourceKey`; другая редакция или ключ останавливают импорт. Флаг `--corrections` позволяет указать отдельный файл. Повторный запуск сохраняет ручные корректировки и воспроизводит пакет.

## Подготовка публичного пакета

Следующая команда создаёт публичную копию пакета и метаданные загрузки. Она не выполняет push и деплой; PDF, корректировки и отчёты не копируются.

```bash
npm run content:prepare-public -- content-private/praktikum-2027/pack.json
npm run content:validate
npm run build
```

При изменении набора увеличьте `packVersion`; для изменённых заданий увеличьте их `version`. Оболочка и библиотека должны публиковаться вместе: их версии и контрольные суммы согласованы.

## Публикация

Источник GitHub Pages — **GitHub Actions**. Ручной workflow собирает и проверяет `dist`, вычисляя базовый путь из имени репозитория. Обычный push запускает CI, но не публикует сайт.

```bash
gh workflow run pages.yml --ref codex/zapyataya-pwa
gh run list --workflow pages.yml
npm run site:check -- https://kirillkaurov3-cloud.github.io/Ekzamen-9-klass-rus/
```

После деплоя проверьте публичный сайт в чистом браузере: прямую ссылку в каталог, решение с разбором, сохранение после перезагрузки и офлайн. Проверка ресурсов через `site:check` не заменяет этот сценарий. Установка на реальных iPhone/Android проверяется отдельно от эмуляции Chromium.

# Запятая

Тренажёр ОГЭ по русскому языку: темы и номера, мини-варианты с таймером, повторение ошибок, теория и локальный прогресс. Интерфейс и самостоятельные демозадания доступны без регистрации. Один браузер — один профиль; синхронизации и журнала класса нет.

## Запуск

Нужен Node.js из `.nvmrc` (24.22.1) и npm. Из корня проекта:

```bash
npm ci
npm run dev
```

Для проверки готовой PWA используйте сборку; обычный dev-сервер не проверяет офлайн-сценарий:

```bash
npm run lint
npm run typecheck
npm test
npm run content:validate
npm run build
npm run preview
```

Адрес preview — `http://localhost:4173`. Сервис-воркер работает на `localhost` или HTTPS. Открытие `index.html` через `file://` и HTTP по адресу компьютера в локальной сети не заменяет проверку PWA.

## Как пользоваться

1. На главной выберите тренировку, затем тему или номер ОГЭ. В демо есть все формы ответа и задания для обоих пресетов мини-варианта.
2. Ответьте, нажмите «Проверить» и откройте разбор. Выход сохраняет позицию и черновик. Ошибочные проверяемые задания попадают в повторение.
3. В мини-варианте можно менять ответы и переходить между вопросами. Проверка и ключи появляются после сдачи. Таймер хранит абсолютный дедлайн и продолжает идти в фоне.
4. В настройках откройте «Загрузить набор», выберите локальный `pack.json`, проверьте название и число заданий, подтвердите. Файл обрабатывается на устройстве, без отправки на сервер.

Перед новой серией или сменой набора завершите текущую сессию либо продолжите её. Повторная загрузка идентичного набора не дублирует историю; конфликт содержимого при тех же ID и версии отклоняется. Демо и импортированный материал имеют разные ID наборов и отдельную статистику.

## Установка и офлайн

- **iPhone:** откройте HTTPS-адрес в Safari → «Поделиться» → «На экран “Домой”». Если доступен переключатель «Открыть как веб-приложение», включите его и нажмите «Добавить».
- **Android / Chrome:** используйте карточку установки, если браузер предлагает системный запрос, либо меню браузера → «Установить приложение» / «Добавить на главный экран».
- Сначала полностью загрузите приложение с сетью. Затем выключите сеть и заново откройте его. Оболочка и демо лежат в кэше, импортированные материалы, черновики и история — в IndexedDB.
- Установленная версия и вкладка браузера могут иметь разные правила хранения на конкретной платформе. Очистка данных сайта удаляет локальный прогресс. Приложение не делает облачную копию.
- Обновление оболочки предлагается отдельной кнопкой. Завершите активную сессию перед применением обновления.

## Импорт пособия

Публичная сборка содержит только самостоятельно составленное демо. PDF, его текст, локальный пакет, корректировки и отчёты находятся в игнорируемых Git каталогах `content-source/` и `content-private/`. Не переносите их в `public/` и не добавляйте в импорты Vite.

Нужны Python 3 и Poppler (`pdftotext`). На macOS: `brew install poppler`; на Debian/Ubuntu: `sudo apt-get install poppler-utils`.

```bash
mkdir -p content-source
# Положите вашу копию PDF в этот каталог либо задайте любой путь через --input.
python3 scripts/import-pdf.py \
  --input content-source/Tematicheskiy_praktikum_2026-2027-2.pdf \
  --output-dir content-private/praktikum-2027
npm run content:validate -- content-private/praktikum-2027/pack.json
```

Импорт сохраняет физические страницы и адреса упражнений, извлекает ключи только поддерживаемых форматов, формирует очередь сверки. Спорные записи не попадают в ученический пакет. Наличие записи в отчёте не означает, что соответствующее упражнение уже перенесено корректно. Точное покрытие и проверенные страницы смотрите в отчёте конкретного запуска внутри `content-private/praktikum-2027/`.

Перед передачей PDF или извлечённого набора одноклассникам организатор отдельно подтверждает право распространять эти материалы. Публикация оболочки сама по себе не передаёт пособие: ученик загружает разрешённый локальный файл через настройки.

## Архитектура и данные

- `src/config.ts` — название и общая конфигурация. Переименование применяется к интерфейсу и manifest при новой сборке.
- `src/app/`, `src/features/`, `src/ui/` — React, hash-маршруты, экраны, адаптивные стили и темы.
- `src/domain/schema.ts` — строгая схема Zod `ContentPack`, одинаковая для CLI и браузерного импорта. Данные декларативные; HTML и исполняемый код из пакета не вставляются в DOM.
- `src/domain/engine.ts` — проверка ответов, нормализация, подбор и статистика.
- `src/storage/` — IndexedDB через Dexie, атомарные операции и миграции. Результат попытки связан с версией задания, ID и версией набора.
- `content-demo/` — собственные учебные примеры, которые можно включать в сборку.
- `scripts/`, `tests/` — воспроизводимый импорт, валидация, аудит сборки и синтетические проверки.

Множественный выбор сравнивает множества ID. Номер `12` не превращается автоматически в позиции `1` и `2`. Текст нормализуется в NFC, приводится к русскому нижнему регистру, крайние и повторные пробелы убираются. Правила для `ё` и слитной записи задаются отдельно для задачи; альтернативы перечислены явно. Самопроверка и пропуски исключены из точности. Точность — доля верных среди проверенных попыток; «Решено верно» — уникальные актуальные задачи с хотя бы одним верным ответом.

## Проверки браузера

```bash
npx playwright install chromium
npm run test:e2e
```

E2E запускается на production-сборке. В тестах используются собственные материалы, без PDF. Проверяются тренировка, восстановление черновика, очередь ошибок, мини-вариант, истечение таймера, импорт и офлайн, а также ширины 360, 390, 430 и 1280 px в двух темах. Скриншоты главной, длинного задания и результата сохраняются в `test-results/`. CI запускает браузерные тесты для корня и `/repo/`; артефакты `browser-results-0` и `browser-results-1` содержат скриншоты. Проверяйте root и префикс отдельно:

```bash
OGE_BASE_PATH=/repo/ npm run build
OGE_BASE_PATH=/repo/ npm run preview
# Отдельный автоматический прогон с тем же префиксом:
OGE_BASE_PATH=/repo/ npm run test:e2e
```

Откройте `http://localhost:4173/repo/#/topics`, проверьте загрузку иконок, `manifest.webmanifest`, `start_url`, `scope` и сервис-воркер. Верните обычную сборку командой `npm run build` без переменной.

Для ручной проверки на реальных устройствах:

1. Опубликуйте демо по HTTPS и установите его на iPhone Safari и Android Chrome.
2. Откройте главную, длинную задачу и результат при ширинах 360, 390, 430 и 1280 px, в светлой и тёмной теме. Проверьте масштаб 200%, системный крупный текст, клавиатуру и уменьшение движения.
3. Прервите тренировку, перезагрузите приложение, проверьте черновик. В мини-варианте уйдите в фон до истечения таймера; после возврата должен появиться один результат.
4. Загрузите разрешённый пакет, выключите сеть, перезапустите приложение и пройдите все основные экраны. Проверьте сохранение ответа.
5. Проверьте установку и обновление уже установленной версии. Эмуляция не подтверждает реальное поведение установки Safari и Chrome.

## Публикация оболочки

Публикация и push выполняются только по отдельной команде владельца. В проекте подготовлен ручной workflow `.github/workflows/pages.yml`; он не запускается от обычного push. `ci.yml` проверяет изменения на push и pull request.

После разрешения на публикацию:

1. Поместите код в GitHub-репозиторий, не добавляя `content-private/` и `content-source/`.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. В **Actions** вручную запустите «Публикация демо на GitHub Pages». Базовый путь вычисляется из имени репозитория; для `<owner>.github.io` используется `/`, для проекта — `/<repo>/`.
4. Откройте URL успешного deployment. Проверьте прямой hash-маршрут, импорт и офлайн.

Обычный GitHub Pages имеет публичный адрес, в том числе для приватного исходного репозитория при поддерживаемом тарифе. Доступ только для приглашённых — отдельная задача хостинга.

Официальные инструкции:

- [Vite: GitHub Pages и base](https://vite.dev/guide/static-deploy#github-pages)
- [GitHub: создание сайта Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)
- [Apple: сайт как веб-приложение на iPhone](https://support.apple.com/ru-ru/guide/iphone/iphea86e5236/ios)
